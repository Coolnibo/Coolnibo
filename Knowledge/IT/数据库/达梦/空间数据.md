使用DMGEO2 或者 DMGEO ，达梦支撑人员推荐使用DMGEO2。

# 创建包
包创建成功后就可以使用空间数据类型以及包提供的方法。
```sql
SP_INIT_GEO2_SYS(1);
```


删除 DMGEO2 包，任何与空间数据类型相关的表、函数、过程、触发器等对象均会被级联删除。
```
SP_INIT_GEO2_SYS(0);
```
# 创建列

数据类型为 `"SYSGEO2".ST_POINT` 

插入/修改数据

```sql
INSERT INTO locations(name, coordinate) VALUES('Location A', ST_PointFromText('POINT(116.3974 39.9093)'));

```

# 方法

常用方法

1. **ST_GeomFromText**‌：这个函数用于将文本形式的地理空间坐标转换为地理空间数据类型。参数`'POINT(116.38333 39.9)'`是你的查询点，`4326`是WGS 84坐标系的SRID（Spatial Reference System Identifier）。
	将`ST_POINT`数据转换成`ST_GEOMETRY`
    
2. ‌**ST_Distance**‌：这个函数计算两个地理空间对象之间的距离，单位通常是米。在这个例子中，它用来计算表中每个点的位置与点A之间的距离。
    
3. ‌**ST_AsText**‌：这个函数将地理空间数据类型转换为文本形式，以便于查看或记录。
4. **ST_POINTFROMTEXT**：
5. **ST_DistanceSphere**：使用球形地球模型返回两个几何对象之间的最小距离。

# SQL

```sql
SELECT * 
FROM MK_CU_RES_COM_SYNC 
WHERE ST_DistanceSphere(
    ST_GeomFromText('POINT(' || ? || ' ' || ? || ')'),  -- 参数点：经度 纬度
    ST_GeomFromText('POINT(' || LONGITUDE || ' ' || LATITUDE || ')')  -- 数据库中的点
) < 500;
```
