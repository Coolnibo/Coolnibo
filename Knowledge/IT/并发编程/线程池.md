# Spring 封装

`ThreadPoolTaskExecutor`
``` java
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.scheduling.annotation.EnableAsync;
import org.springframework.scheduling.concurrent.ThreadPoolTaskExecutor;
import java.util.concurrent.Executor;
import java.util.concurrent.ThreadPoolExecutor;

@Configuration
@EnableAsync
public class AsyncConfig {

    @Bean("orderTaskExecutor")
    public Executor orderTaskExecutor() {
        ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
        // 核心线程数：根据 IO 密集型场景调整，通常可设为 CPU 核数 * 2
        executor.setCorePoolSize(8);
        // 最大线程数
        executor.setMaxPoolSize(16);
        // 队列容量：务必设置有界队列，防止 OOM
        executor.setQueueCapacity(200);
        executor.setKeepAliveSeconds(60);
        // 关键：设置线程名前缀，排查日志时能直接定位业务
        executor.setThreadNamePrefix("order-async-");
        // 生产环境推荐 CallerRunsPolicy，过载时由调用线程执行，起到背压作用
        executor.setRejectedExecutionHandler(new ThreadPoolExecutor.CallerRunsPolicy());
        // 优雅停机：等待任务执行完再关闭
        executor.setWaitForTasksToCompleteOnShutdown(true);
        executor.setAwaitTerminationSeconds(30);
        executor.initialize();
        return executor;
    }
}
```

# 多任务并发并拿到所有结果

`CompletableFuture` 是 Java 8 引入的**异步编程与任务编排**工具，位于 ``java.util.concurrent`` 包下，实现了 `Future` 和 `CompletionStage` 两个接口。一句话概括：**它让你能把"异步执行一个任务"和"任务完成后再做什么"用声明式的方式串起来，而不必手动阻塞等待或写回调地狱。**

```java
CompletableFuture<A> fa = CompletableFuture.supplyAsync(() -> callA(), executor);
CompletableFuture<B> fb = CompletableFuture.supplyAsync(() -> callB(), executor);
CompletableFuture<C> fc = CompletableFuture.supplyAsync(() -> callC(), executor);
// 三个全部完成后，合并结果
CompletableFuture<String> combined = CompletableFuture.allOf(fa, fb, fc)
    .thenApply(v -> fa.join() + fb.join() + fc.join());
```
